# LinkedIn Posting Schedule

Two posts a week: **Tuesday 7:30am** and **Thursday 8:00pm** Brisbane time. Those are the
windows venue operators actually look at their phones (pre-prep and post-service).

## How to run it

LinkedIn has no public API for personal-profile auto-posting, so the automation is a
scheduler, not a bot:

1. **LinkedIn native scheduler (free, recommended):** write post → click the clock icon next
   to Post → pick date/time. You can queue everything a month ahead in one sitting.
2. **Buffer free plan** (10 queued posts, one LinkedIn profile) if you want a single dashboard.
3. Copy each post from `posts-a.md` / `posts-b.md`, attach the matching card from `images/`,
   schedule, done. ~30 minutes a fortnight.

**Link rule:** LinkedIn suppresses posts with external links in the body. Every post below ends
with `[link in first comment]`. Post it, then immediately comment with the article URL yourself.

**Image rule:** every card in `images/` was generated by us. No stock, no licensing risk. Regenerate
any time with `python3 make-cards.py` (uses the bundled headless Chromium).

set runs later, once the profile has an audience.

same topic within 48 hours. Momentum beats the calendar.
